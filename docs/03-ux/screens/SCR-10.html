The Total Tool Cost sits below the parts so that no part's own Tool Cost cell is replaced (the first part's own Tool Cost is in the Tool Cost cell of row 2). BN2 divides BL2 by it.

How BL2 is made

How to reconcile.Add the BG column of the file. That gives BL2, at any quantity. Each row's BG already holds the count for the whole order that the Engineer typed, so nothing is multiplied by the rows above. For example, for 2 frames, 6 pipes and 24 lids the Engineer types 2, 6 and 24.

Figures are shown to 2 decimals. Totals add the unrounded values and round once, so adding the shown figures by hand can differ by a few hundredths. The lines of the table above add to 12,951.55 as shown, and the total is 12,951.53.

What the file holds

  • Header row 1; columns A to BO; same widths; every cell centred
  • Currency formats: ₹ for INR, $ for USD, € for EUR
  • Part picture in column C, scaled to fit
  • Sl. No kept as text, so 1.10 stays 1.10
  • Every column exported, including hidden treatment lines as 0
  • A divide by zero is an empty cell
  • Every part keeps its own Tool Cost in its own row
  • One Total Tool Cost, in the Tool Cost column of row 15, below the last part and labelled in the cell to its left
  • No warning cell: a quantity warning is shown on the estimate and here, never in the file (A-24)
  • No file at all until a calculation is current: not for a never-calculated estimate and not while the total is cleared

File name (CR-01): <Customer Short Name>_<Subject>_<DD-MM-YYYY>.xlsx, for example BWC_CC-40-cabinet_05-11-2026.xlsx. The date is the IST date of the download. Spaces and the characters / \ : * ? " < > | in the subject become hyphens, and the name is cut at 100 characters before .xlsx. Two downloads on one day give the same name; the browser keeps both. Download marker: each download is recorded (who, when) and shown as "Downloaded" on the queue and the estimate; it turns amber, "Changed since download", when the estimate is approved again after the last download. No file until a calculation is current (their answers, Q-37 (b) and A-32): for a never-calculated estimate and while the total is cleared the page says why, links to Calculate or Recalculate, and shows no table and no file card. There is no out-of-date file, no marked file name and no confirmation any more. Position of the Total Tool Cost (agrees with architecture 4.6): row 15 of the Tool Cost column, after one empty row, with its label in the cell to the left, leaves row 2 and every part's own Tool Cost cell untouched.
