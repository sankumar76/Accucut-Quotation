Design system

One set of tokens drives every screen: four type sizes, a 4-point spacing scale, one button size in four variants and one palette. All values are in screens.css. "Red Leads" brand, delivery lead decision of 2026-10-31.

01

Brand: Red Leads

Delivery lead decision
ACCUCUT LASERS Quotation Portal

White top bar. The logo is the supplied file, shown unaltered at 56 px (44 px on phones). The name is Tinos Bold, which is the closest match to the company board, in logo red.

  • Logo file used as supplied; never redrawn, recoloured, cropped or stretched. It needs a light background, so the top bar is white.
  • "ACCUCUT LASERS" in logo red (#DE3030, 4.6:1 on white), 18 px bold serif with wide letter spacing.
  • Dark graphite side menu (#17181C). Active item: lighter graphite plus a red marker.
  • Red main buttons. Overdue and attention use amber, never red. Errors use a separate darker red and always carry an icon, a thick border and text.
  • The logo is 200 × 200 px. A sharper original (open question Q-16) will replace the file; nothing else changes.

05

Buttons

One size: 44 px high, 16 px side padding, 8 px radius, 14 / 600

Primary = the one main action on a screen (red). Secondary = other actions. Ghost = low-emphasis, inline. Danger = deletes only, in the error red with a trash icon and the word "Delete". Icon-only buttons always carry an accessible name. Focus ring: 3 px graphite, 2 px offset (white on the dark menu).
