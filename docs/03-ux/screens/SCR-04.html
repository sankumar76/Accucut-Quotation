What happens next

  1. An empty estimate is created in Draft with a task ID like Q-2026-0324.
  2. It appears in the Engineer's Open queue, sorted by deadline.
  3. The Engineer chooses the customer and enters the part data.
  4. If e-mail alerts are ON, the Engineer is e-mailed and you are copied (Release 2).
How the folder link works

Everyone sees the path as a link plus a Copy path button. Browsers often block links to network folders; the button always works.

Your browser may block links to network folders. If nothing opens, choose Copy path and paste it into File Explorer.
