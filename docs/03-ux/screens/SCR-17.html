Review note. Release 2 (FR-072 to FR-080). Admin sees insert on each row, edit formula where there is a formula to edit, and delete except on system fields (A, H, BG, BL, BO) that the portal needs; those show a lock tag. The server refuses the same actions. "Kind" says who sees the field: an Input is on the Engineer's form; an Output is never sent to an Engineer. Letters are derived from position and never stored.
