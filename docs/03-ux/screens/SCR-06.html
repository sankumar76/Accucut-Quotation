How the total is built

Show

The Engineer types the count for the whole order on every row (QTY per Assy, column H). Each row's cost (column BG) already includes its own count, so the total is the BG of every row added together. Nothing is multiplied by the rows above. For example, for 2 frames with 6 pipes and 24 lids in all, the Engineer types 2, 6 and 24. If one lid costs 1, one pipe costs 1 and the frame row holds nothing, the lid row shows 24, the pipe row 6 and the frame row 0, and the total is 24 + 6 + 0 = 30.

In this estimate, row 1.1.1 has a count of 16: 2 control cabinet assemblies, 2 base frames in each and 4 corner gussets on each frame, typed as 16 on that row.
